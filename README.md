# Mechakov

프롭 헌트식 3인칭 멀티플레이 게임. 레이드에서 아이템을 챙겨 탈출하고, 은신처에서 업그레이드하는 타르코프식 루프를 더해 갈 예정입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열고 방 이름을 비워 두면 빠른 매칭으로 입장해요. 친구와 같은 방에 들어가려면 같은 방 이름을 쓰면 돼요. 혼자 테스트할 때는 대기실에서 B를 눌러 프롭 봇을 추가하면 내가 헌터로 라운드가 시작돼요.

서버 없이 혼자 하려면 입장 화면에서 '혼자 하기'를 누르면 돼요. 게임 서버가 브라우저 안에서 같이 돌아요. 지금은 헌터 없이 나와 봇 3명이 모두 프롭이라, 아이템을 챙겨 탈출구로 나가는 연습을 할 수 있어요 (탈출구는 처음부터 열려 있어요). 레이드 사이에는 은신처 방을 걸어 다녀요. 보관함 앞에서 F를 누르면 창고를, 작업대 앞에서 F를 누르면 업그레이드를 볼 수 있고, 초록 출구 문 앞에서 F를 누르면 다음 레이드 맵으로 출발해요. 내가 탈출하거나 죽으면 바로 은신처로 돌아와요. `npm run build:web`은 이 혼자 모드만 담은 HTML 파일 하나(`dist-web/mechakov.html`)를 만들어서, 정적 호스팅 어디에나 올릴 수 있어요.

배포용으로는 클라이언트를 빌드한 뒤 서버 하나로 게임과 웹페이지를 함께 띄웁니다.

```bash
npm run build
npm start          # http://localhost:2567, PORT 환경 변수로 변경 가능
```

## 지금 들어 있는 것 (1단계)

- 2~12명이 한 방에서 플레이. 라운드마다 약 4명 중 1명이 헌터, 나머지는 프롭
- 숨는 시간 40초 (헌터는 화면이 가려지고 못 움직임), 이후 사냥 4분
- 프롭: 가까운 사물을 보고 E로 그 사물로 변신, R로 몸 방향 고정
- 헌터: 클릭 사격. 프롭 명중 시 25 피해, 가짜 사물을 쏘면 자기 체력 5 감소
- 프롭이 한 명이라도 아이템을 챙겨 살아나가면 프롭 승리, 아니면 헌터 승리
- 서버가 이동과 사격을 판정하고, 클라이언트는 예측과 보간으로 부드럽게 표시

## 레이드와 은신처 (2단계)

- 숨는 시간과 사냥 시간 동안 맵 곳곳에 아이템이 생겨요. 프롭은 F로 주워 가방에 담아요 (기본 3칸).
- 사냥 중 초록색 탈출구에 5초 서 있으면 탈출하고, 가방 속 아이템이 보관함으로 들어가요.
- 프롭이 죽으면 가방은 그 프롭을 잡은 헌터에게 넘어가요. 헌터는 라운드 끝까지 살아남아야 챙길 수 있어요.
- 시간이 끝날 때까지 탈출하지 못한 프롭은 가방을 잃어요.
- H로 은신처를 열어 보관함 아이템으로 업그레이드해요: 가방 칸 수, 이동 속도, 최대 체력, 변신 가능한 사물(변신 도감), 헌터 헛발질 피해(조준경).
- 계정은 브라우저에 저장된 토큰으로 구분하고, 서버는 `data/profiles.json`에 저장해요 (`PROFILES_FILE`로 경로 변경).

## 콘텐츠 (3단계)

- 맵 3종 (100m × 100m), 맵마다 세부 구역이 있고 구역 컨셉에 맞는 사물이 놓여요. 지금 있는 구역은 화면 위쪽에 떠요.
  - 창고: 선반 통로가 있는 보관 창고, 사무 구역(사무실, 관리자실, 휴게실), 정비실, 하역장
  - 사무실: 복도, 오픈 오피스 두 곳, 회의실, 서버실, 임원실, 복사실, 라운지, 창고방
  - 야적장: 컨테이너 구역, 정비 창고, 자재 적치장, 연료 저장소, 공사 현장, 하역장, 경비실, 폐타이어장
- 라운드가 끝날 때마다 다음 맵으로 바뀌어요.
- 빠른 매칭: 방 이름을 비우면 대기 중인 방 중 사람이 가장 많은 곳에 들어가요. `/rooms`에서 접속자 수를 볼 수 있어요.
- 프롭 봇(최대 6): 근처 사물로 변신해 숨었다가 시간이 끝나기 전에 탈출구로 가요. 봇은 프롭만 하고, 사람이 들어오면 자리를 비켜줘요.
- 밸런스: 헌터는 프롭을 잡을 때마다 고철, 볼트, 전선 중 하나를 보상으로 받아요. 아이템 수는 인원에 맞춰 16 + 인원×4개.

## 출시 준비 (4단계)

- 헌터는 벽 너머에 있는 프롭의 위치를 아예 받지 않아요. 수정한 클라이언트로 벽 너머를 보는 치트를 막아요.
- 메시지 크기(4KB)와 초당 메시지 수를 제한하고, 같은 IP에서 6개까지만 접속할 수 있어요.
- 닉네임에서 보이지 않는 문자와 제어 문자를 지워요.
- `Dockerfile`과 `fly.toml`이 있어요. 올리는 방법은 [DEPLOY.md](DEPLOY.md)를 보세요.

## 구조

| 폴더 | 내용 |
| --- | --- |
| `shared/` | 서버와 클라이언트가 같이 쓰는 규칙: 맵 생성(시드 기반), 이동 물리, 사물 목록, 메시지 형식 |
| `server/` | Node + ws 게임 서버. 30Hz로 시뮬레이션하고 상태를 보냄 |
| `client/` | Vite + three.js 클라이언트 |
| `tests/` | 물리와 라운드 진행 테스트 (`npm test`) |

## 조작

WASD 이동 · Space 점프 · Shift 달리기 (스태미나 6초, 다 쓰면 35% 찰 때까지 못 달림) · E 변신 · R 방향 고정 · 클릭 사격 · Tab 인벤토리 (가방, 보관함, 참가자) · M 소리 끄기/켜기
